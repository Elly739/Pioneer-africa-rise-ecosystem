# Project architecture rules

- Keep global navigation organized around five core destinations, with secondary pages in menus, so the app remains scannable as features grow.
- Render the signed-in AI Mentor as a shared floating launcher from the global navigation layer so it is consistently reachable without occupying a primary tab.
- Keep a private conversation to one row per pair of members and readable only by its two participants, so a chat between the same people never splits; staff may read a conversation only after it has been reported, and widening that needs an explicit decision first.
